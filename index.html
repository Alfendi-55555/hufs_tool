🍚 외대생 맛집 지도

한국외대 서울캠퍼스 학생을 위한, 학생 맥락 기반 맛집 리뷰 서비스

지도 모드 확인 중… ⚠ 리뷰 데이터는 이 브라우저에만 저장됩니다
📌 이용 안내 (처음이시면 펼쳐보세요)
  1. 지도에서 핀을 누르면 그 가게의 상세 정보와 학생 리뷰를 볼 수 있어요.
  2. 리뷰를 쓸 때 가격대 / 혼밥 가능 / 방문 시 영업 여부 / 공부(작업) 가능 / 콘센트·와이파이를 체크하면, 다른 학생이 왼쪽 필터로 조건에 맞는 가게만 골라 볼 수 있어요.
  3. 주변 가게 불러오기를 누르면 카카오 장소 데이터에서 학교 반경 안의 실제 음식점·카페를 상호·주소째로 가져옵니다. (카카오맵 모드에서만)
  4. 목록에 없는 가게는 새 맛집 등록으로 지도를 클릭해 직접 추가할 수 있어요.
※ 가게의 상호·주소·좌표는 카카오 장소 데이터에서 오고, 혼밥·콘센트·공부 가능 여부 같은 학생 맥락 정보는 우리 학교 학생들의 리뷰로 쌓입니다. 영업 상태는 실시간 정보가 아니라 최근 방문한 학생의 제보이니 방문 전 확인하세요.
※ 카카오 JS 키가 없으면 실제 지도 대신 간이 배치도로 동작합니다 (위치 관계는 실좌표 기반이지만 축척·도로 모양은 정확하지 않음). 키 설정은 왼쪽 지도 설정 버튼에서 합니다.

⚙ 지도 설정

카카오맵 JS 키를 넣으면 실제 지도와 실제 가게 검색을 쓸 수 있습니다.
  1. 카카오 개발자 사이트에서 애플리케이션을 만들고 JavaScript 키를 발급받으세요.
  2. 그 앱의 플랫폼 > Web에 이 페이지를 띄울 주소를 등록하세요. (예: http://localhost:8000)
  3. 카카오맵은 file://로 연 페이지에서는 동작하지 않습니다. 폴더에서 아래 명령으로 띄운 뒤 http://localhost:8000/team-tool.html 로 접속하세요.
    python -m http.server 8000
  4. 발급받은 키를 아래에 붙여넣고 저장하세요. 키는 이 브라우저에만 저장됩니다.
